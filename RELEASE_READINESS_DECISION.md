# Решение о готовности 1.0.8-pre1

**NOT READY.** Переход к Release Automation отложен до закрытия блокеров.

| Блокер | Свидетельство | Критерий закрытия |
| --- | --- | --- |
| Авторизация MCP | Renderer владеет диалогом согласия, а main MCP принимает вызовы через preload. | Проверка согласия в доверенном main, одноразовое связывание с окном и действием, регрессионное подтверждение отказа. |
| Подлинность и политика обновлений | HTTPS, SHA-256 и проверка канала присутствуют. Независимая подпись manifest и защита от downgrade по порядку версий не подтверждены. | Политика доверия к manifest, привязка ключа и канала, проверенный отказ для устаревшего или неверно подписанного metadata, безопасная политика legacy. |
| Windows installer/updater | VM нет. Локальное staging не доказывает замену, restart или rollback. | Полный lifecycle в одноразовой Windows x64 VM, включая успешный rollback после нативной передачи управления и проверку SQLite. |
| Изоляция каналов | Артефакты проверялись ранее, профиль Windows по умолчанию общий. | Подтвердить фактические установки, ярлыки, записи, запрет cross-channel update и согласовать ожидаемую изоляцию профиля. |
| Clean build и CI | Пустой Hutch home ранее упал на Cottontail. Actions не запускался. | Холодная сборка в VM и безопасная CI-проверка без публикации, проверка содержимого артефактов перед release. |
| Остаток обзора исходников | Нет полного покрытия RPC, сетевых и архивных маршрутов. | Закрыть матрицу маршрутов и повторить критические проверки с синтетическими данными. |

Исключение Moderate по minimatch задокументировано. Оно не отменяет обязательных блокеров выше.

# Валидация артефактов предварительного выпуска

Скрипт scripts/validate-pre-release.ts проверяет точный список пяти файлов кандидата, размер, формат PE x64, имя продукта, App ID, версию и канал. Он сверяет SHA-256 и размер из v2-манифеста с байтами архива, сравнивает вложенный архив ZIP, проверяет присутствие проверенного ZIP внутри автономного установщика, просматривает имена упакованных файлов и проверяет отсутствие URL обновлений и значений OAuth в main bundle. Проверка секретов ограничена сгенерированной конфигурацией, правилами имён и явными сигнатурами ключей. Canary metadata или неожиданные файлы приводят к отказу. Для публикации создаются установщик и SHA256SUMS.txt.

Проверка читает артефакты как данные. GUI-установка и откат требуют одноразовой Windows VM.

Локальная проверка на Bun 1.4.4 завершилась кодом 0. Первый запуск валидатора вернул 1, поскольку v2 описывает распакованный TAR. Проверка исправлена и повторена. SHA-256 локального автономного установщика: 655fc9af50c320c99690a343e3fb1165426bcbe62f26c2e97a862f56f054ee28. Это хеш локального кандидата. Runner пересчитывает хеш своего артефакта.

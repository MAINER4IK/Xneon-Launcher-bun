# Аудит безопасности Xneon Launcher

**Вердикт второго раунда — SECURITY AUDIT PASSED WITH WARNINGS** для проверенной области Windows. Обязательные сценарии VM и полный обзор оставшихся границ открыты.

## Первый раунд (история)

**Вердикт первого раунда — SECURITY AUDIT FAILED.** Это частичный аудит. Проверка зависимостей после исправлений сохраняет 20 уведомлений High. Их достижимость в лаунчере оценена лишь частично. Полный охват исходников и обязательная проверка Windows в VM остаются условиями выпуска.

## Зависимости

`bun audit` до изменений — 46 уведомлений (1 Critical, 27 High, 14 Moderate, 4 Low). После изменений — 35 (20 High, 11 Moderate, 4 Low). Устранены 11 совпадений в графе. Обновление затронуло `adm-zip`, `toml`, `shell-quote` и прямой `axios`. В рабочем коде ZIP используется при облачном импорте и установке Java, TOML — при разборе метаданных модов. Критическое уведомление `shell-quote` относилось к зависимости инструмента разработки `concurrently`. Достижимость через внешние данные приложения не установлена. Остаток и пути к пакетам перечислены в отчёте о рисках.

Источники — [Bun audit](https://bun.com/docs/pm/cli/audit), [advisory adm-zip](https://github.com/advisories/GHSA-7q85-xj36-vmfc), [advisory toml](https://github.com/advisories/GHSA-4qx8-w7c3-pj3p), [advisory shell-quote](https://github.com/advisories/GHSA-pqg4-j6r4-53mv), [advisory axios](https://github.com/advisories/GHSA-m8m8-qj5v-23w3).

## Границы проверки

Рассмотрены отдельные пути Agent, MCP, AI-настроек, импорта, обновления, WebView и SQLite. Проверены свойства защитных механизмов и совместимость. Сценарии эксплуатации и PoC исключены из методики. Уведомления поставщиков пакетов учитываются отдельно от замечаний по исходникам.

# Windows VM — статус финальной проверки

**Не выполнена.** Доступная одноразовая Windows x64 VM с WebView2 не обнаружена. В проекте нет образа или конфигурации гостя, команды Hyper-V/VirtualBox/VMware для управления гостем недоступны. Установщик и unpacked launcher на хосте не запускались.

| Сценарий | Результат |
| --- | --- |
| Конфигурация гостя, snapshot, реестр, Desktop, Start Menu, установленные приложения | Данных нет |
| Stable install, WebView2, профиль, SQLite, остановка | Ожидает VM |
| Stable uninstall, ярлыки, реестр, профиль, повторная установка | Ожидает VM |
| Canary install, отдельная установка и сосуществование | Ожидает VM. Код профиля показывает общий профиль по умолчанию, изоляцию данных нельзя считать пройденной. |
| Stable N → N+1, handoff, атомарная замена и рестарт | Ожидает VM |
| Ошибки загрузки, подменённый хеш, отказ handoff, сбой после handoff, rollback | Ожидает VM. В предыдущем раунде проверена только подготовка пакета. |
| Downgrade, повтор того же пакета, manifest соседнего канала | Ожидает VM |
| Состояние гостя после тестов | Данных нет |

План и команды сбора доказательств находятся в WINDOWS_VM_VALIDATION.md и scripts/snapshot-security-vm.ps1. Для закрытия нужны исходный и конечный снимки, хеши бинарника, версии, состояния реестра и ярлыков, контрольная запись в SQLite, а также журналы фаз updater. Перед каждым разрушительным сценарием требуется новый snapshot гостя с синтетическим профилем.

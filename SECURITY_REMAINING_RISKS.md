# Оставшиеся риски

## Блокеры проверки выпуска

- Повторный `bun audit` завершился кодом 1. Остались 35 уведомлений, включая 20 High. Проверить совместимые обновления и достижимость для `@modelcontextprotocol/sdk → ajv → fast-uri`, `axios → follow-redirects`, `wait-on → axios/joi`, `webdav → minimatch → brace-expansion` и `postcss → source-map-js`. Часть родительских пакетов закрепляет точную версию. Полные результаты сохранены в `.tmp/security-validation/audit-after.log`.
- Провести установку, деинсталляцию, проверку реестра, ярлыков, ACL, WebView2 и фактический нативный handoff в одноразовой Windows x64 VM. Проверить запуск новой версии, сбой после handoff и фактический rollback отдельно.
- Закрыть пробелы покрытия перед выдачей проходного вердикта. Нужны сквозная инвентаризация RPC, OAuth всех поставщиков, локальных секретов, сетевых ограничений и ссылок/лимитов для всех форматов архива.

## Открытые вопросы

- XNL-02–04. Защита облачных токенов, минимизация передачи AI-ключа в renderer и безопасная обработка ошибок AI.
- MCP. Проверка подтверждения в main, изоляция stdio, схемы аргументов и предельные размеры ответов на транспортном уровне. Существующие лимиты длины сериализованного ответа применяются после получения данных.
- Импорт. `adm-zip` обновлён. Общие бюджеты входного и распакованного размера, количество записей, коллизии имён, сохранение целостности при прерванном импорте и устойчивость к гонкам файловой системы требуют отдельной проверки.
- Сеть. Проверены только отдельные контроли. Для пользовательских WebDAV и AI endpoint требуется определить доверенные исключения для локальной сети и проверить маршрутизацию секретов.
- Исполняемые сторонние JAR. Проверка hash обеспечивает целостность относительно ожидаемого значения. Статус проверки происхождения и границы запуска необходимо документировать по каждому поставщику.
- Ограниченный поиск по сигнатурам приватных ключей, GitHub, OpenAI и AWS нашёл один пример в поле ввода S3. Остальные форматы секретов, история Git и неотслеживаемые файлы этим поиском не покрыты.


## Состояние после второго раунда

- Из 35 прежних advisories осталось одно Moderate по `minimatch@9.0.9`. Условие исключения и доказательства вызова WebDAV указаны в `DEPENDENCY_SECURITY_MATRIX.md`. Все прежние High сняты повторным аудитом. Список выше сохранён для истории.
- Windows VM не запускалась. Установка, удаление, реестр, ярлыки, WebView2, фактический handoff и rollback остаются обязательными. Синтетические испытания DPAPI выполнены без запуска лаунчера или установщика.
- DPAPI зависит от того же Windows-пользователя. Новое сохранение на платформах без OS secret storage завершается явной ошибкой. Старый JSON читается на этих платформах, но обновление секретов требует реализации системного хранилища. Резервные копии до миграции, страницы SQLite и WAL требуют отдельной политики хранения.
- При смене AI endpoint, включая путь, или протокола потребуется ввести ключ заново. Существующие конфигурации с реквизитами в URL, query, fragment или перенаправлением требуют чистого конечного endpoint. Проверка всех живых провайдеров остаётся открыта.
- Остаток исходного аудита — внешний вывод модели в успешном ответе, сырые ошибки облачных поставщиков, полный обзор RPC, защита архивов и изоляция MCP stdio. Отсутствие High в Bun Audit не закрывает эти проверки.

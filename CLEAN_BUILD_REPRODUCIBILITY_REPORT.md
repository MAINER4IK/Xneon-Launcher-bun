# Воспроизводимость чистой сборки

**Статус: не подтверждена.**

Чистый прогон в Windows x64 VM отсутствует. В предыдущем раунде подготовка с пустым Hutch home остановилась с кодом 1 на компоненте Cottontail и сообщением ReleaseDownloadFailed. Ранее загрузка Bun toolchain через Hutch также завершалась HttpConnectionClosing. Безопасные журналы не содержат URL назначения для отказа Cottontail и HTTP status. Различить сбой CDN, proxy или Hutch по этому свидетельству нельзя.

Локальная проверка с Bun 1.4.4, Electrobun 2.0.6 и подготовленным кэшем Hutch 0.29.0 ведётся отдельно. Она подтверждает локальные Stable/Dev артефакты и frozen lockfile, а не воспроизводимость холодной сборки. GitHub Actions не запускался.

Критерий закрытия — Windows x64 VM, новая копия проекта без .env, секретов и пользовательских кэшей, Bun 1.4.4 и Hutch 0.29.0. Выполнить frozen install, prepare, Stable, Dev и проверку артефактов каналов по заданию. При отказе отдельно сохранить этап, компонент, HTTP status и URL, если они доступны без раскрытия данных. Сборку с проверенным кэшем регистрировать отдельным результатом.

Финальный локальный прогон с подготовленным кэшем и синтетическими значениями генератора завершился успешно. Stable/Dev и frozen install вернули 0. В Stable Hutch пропустил дельта-патч из-за HttpConnectionClosing при запросе метаданных предыдущего релиза. Полная последовательность и логи указаны в FINAL_SECURITY_GATE_REPORT.md. Сетевой отказ холодного toolchain и валидация чистой VM остаются открыты.

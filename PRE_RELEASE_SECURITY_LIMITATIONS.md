# Ограничения безопасности 1.0.8-pre1

Экспериментальная сборка предназначена для контролируемой ручной установки. Main для версии 1.0.8-pre1 регистрирует отказы для проверки, загрузки и установки обновлений и не подключает SDK обработчики этих операций. В метаданных пакета URL обновлений пуст. Manifest и пакет автоматического обновления не публикуются. Это временное отключение, FSG-02 (подпись manifest) и FSG-03 (downgrade) остаются открытыми.

Привилегии MCP renderer, полный FSG-04, минимatch Moderate, проверка Windows VM, rollback и воспроизводимость чистой сборки остаются открытыми. Сборка исключает приватные OAuth credentials. Провайдеры, которым нужны эти данные, требуют отдельной конфигурации перед использованием. Ключи пользователей в контрольном прогоне не использовались.
